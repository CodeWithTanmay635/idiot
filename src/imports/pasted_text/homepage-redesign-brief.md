FIX THE CURRENT HOMEPAGE DESIGN — DO NOT START A COMPLETELY DIFFERENT DESIGN

The current design has the right general ingredients but the composition is poor.

Keep the existing visual direction:
- cinematic
- dark
- editorial
- experimental
- premium
- minimal
- typography-driven
- black + white + orange

But significantly improve the layout, hierarchy, image visibility and spacing.

IMPORTANT:
Do NOT add new visual styles.
Do NOT turn this into a dashboard, SaaS website, government website or classified-document UI.

The current result feels too much like a black left sidebar placed next to a photo.

REMOVE THAT FEELING.

━━━━━━━━━━━━━━━━━━━━━━
MAIN PROBLEM — COMPOSITION
━━━━━━━━━━━━━━━━━━━━━━

The current homepage has a huge solid black vertical block on the left and the hero image pushed to the right.

This creates two disconnected halves:

BLACK PANEL | PHOTO

Do NOT use this composition.

Instead, the entire viewport should feel like ONE continuous cinematic composition.

The hero photograph should occupy a large central portion of the viewport, while the typography and metadata are layered around it.

Use the black background as an environment, NOT as a giant rectangular panel.

Avoid obvious vertical divisions between the text area and image area.

━━━━━━━━━━━━━━━━━━━━━━
HERO IMAGE
━━━━━━━━━━━━━━━━━━━━━━

The person's photograph is the visual centerpiece.

Make the photograph significantly more visible.

The current image is far too dark and hidden behind overlays.

Keep the cinematic dark treatment, but preserve:
- face
- clothing
- silhouette
- important details
- photographic depth

Do NOT place a heavy black overlay over the entire photograph.

Use a subtle gradient only where necessary to maintain text readability.

The image should feel rich and photographic, not almost completely black.

The photograph should occupy approximately 55–70% of the visual attention of the desktop viewport.

Do not put it inside a generic card.

Do not use rounded corners.

━━━━━━━━━━━━━━━━━━━━━━
TYPOGRAPHY
━━━━━━━━━━━━━━━━━━━━━━

The current typography is too cramped and visually aggressive.

Create a clear hierarchy.

Use:

Bebas Neue:
for the major title and person's name.

Inter:
for descriptions and readable text.

Space Mono:
for tiny metadata.

The person's name should be large, but NOT so large that it destroys the photograph.

The title should interact with the image rather than simply covering it.

Suggested hierarchy:

THE SUBJECT

ROHAN

The name should be the main typographic element.

"THE SUBJECT" can be smaller and muted.

Do NOT stack huge text blocks like:

ROHAN
ALANGE

if that creates unnecessary visual clutter.

Use the actual person's name exactly as provided by the project.

━━━━━━━━━━━━━━━━━━━━━━

METADATA

The metadata is currently too prominent and fragmented.

Do not create large boxes around metadata.

Do not make metadata compete with the person's name.

DESCRIPTION

Do not make the description too small.

DESIGN PHILOSOPHY
━━━━━━━━━━━━━━━━━━━━━━

The final homepage should feel like a premium experimental editorial portrait website.

It should look beautiful BEFORE the visitor reads anything.

Then the text reveals that this beautiful website was inexplicably created for an idiot.

Beautiful UI.
Beautiful photograph.
Serious presentation.
Funny subject.

Do not make the interface itself look like a meme.

Prioritize:
1. composition
2. photograph visibility
3. typography hierarchy
4. negative space
5. visual balance
6. responsive behavior
7. subtle interaction

Do not add unnecessary features.
