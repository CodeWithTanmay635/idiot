DESIGN THE "THE CRIMINAL" PAGE

This page is a fictional, humorous criminal dossier about the subject.

It should look like a serious forensic / criminal investigation interface documenting a dangerous criminal suspect.

The humor comes from the information being absurd and sarcastic.

IMPORTANT:
This is a parody birthday website.
The subject is a friend.
"Criminal" is a humorous fictional characterization, not a real accusation.

Use the attached visual reference as the PRIMARY layout inspiration.

Do NOT create a generic portfolio page.
Do NOT create a normal "About Me" page.
Do NOT create a modern SaaS dashboard.
Do NOT use colorful cards or gradients.

The page should feel like an old-school forensic database / classified criminal record interface.

━━━━━━━━━━━━━━━━━━━━━━
OVERALL VISUAL STYLE
━━━━━━━━━━━━━━━━━━━━━━

Dark forensic terminal / criminal database aesthetic.

Visual characteristics:

- almost black / charcoal background
- monochrome gray interface
- subtle green terminal-style accents
- very small technical labels
- thin borders
- dense information layout
- monospace typography
- subtle scanline / terminal feeling
- restrained UI
- photographic evidence
- data-heavy composition

The page should feel like someone accessed a confidential criminal database.

Use green as the primary accent for this page.

Do NOT use the orange accent from the homepage heavily here.

The website should still feel like the same overall universe, but this page is allowed to have a forensic green accent because it represents a criminal database.
