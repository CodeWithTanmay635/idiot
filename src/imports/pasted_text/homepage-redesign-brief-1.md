REDESIGN THE HOMEPAGE AS A SINGLE-SCREEN INTERACTIVE MAIN MENU.

Do not create a scrolling landing page.
Do not create multiple sections below the fold.
The entire homepage must fit inside ONE viewport.

DESKTOP FRAME:
1440 × 900

MOBILE FRAME:
390 × 844

The design must be responsive, but both versions should be intentionally composed for their respective screen sizes.

━━━━━━━━━━━━━━━━━━━━━━
CORE CONCEPT
━━━━━━━━━━━━━━━━━━━━━━

This is a funny birthday website created for a close friend.

The website should NOT look like a traditional birthday website.

Do NOT use:
- balloons
- confetti
- birthday cakes
- pink/purple birthday gradients
- generic birthday templates
- childish UI

Instead, make it feel like a cinematic experimental website / game main menu.

The interface should look serious, stylish and premium.

The content is the joke.

The visual concept is:

"An unnecessarily beautiful digital archive was created for this absolute idiot."

━━━━━━━━━━━━━━━━━━━━━━
HOMEPAGE STRUCTURE
━━━━━━━━━━━━━━━━━━━━━━

The homepage contains ONLY:

1. Minimal top navigation
2. Hero photograph of the subject
3. Subject name
4. Very short introduction
5. Three navigation buttons

The three destinations are:

PHOTOS

THE CRIMINAL

SPECIAL ROOM

There must be NO other major homepage sections.

No scrolling should be necessary on desktop.

━━━━━━━━━━━━━━━━━━━━━━
VISUAL STYLE

Use:

- cinematic
- dark
- editorial
- experimental
- modern
- minimal
- image-focused
- premium

The entire viewport should feel like ONE composition.

Do NOT divide the page into a rigid:
LEFT BLACK PANEL | RIGHT IMAGE

Do not create a large rectangular sidebar.

The black background should act as an environment around the photograph.

━━━━━━━━━━━━━━━━━━━━━━
HERO IMAGE
━━━━━━━━━━━━━━━━━━━━━━

Use the provided photograph of the subject as the primary visual.

The photograph should be clearly visible.

Do NOT make it almost black.

Do NOT cover the face with text.

Do NOT put the photograph inside a generic rounded card.

Do NOT use a conventional website hero-card layout.

Treat the photograph as a cinematic portrait.

Use subtle darkness/gradient around it to integrate it with the black environment.

The photograph should occupy a large portion of the visual composition.

━━━━━━━━━━━━━━━━━━━━━━
SUBJECT
━━━━━━━━━━━━━━━━━━━━━━

Use a small editorial label:

001 / SUBJECT PROFILE

Then the main identity:

THE SUBJECT

[FRIEND'S NAME]

The friend's name should be large and visually important.

However, it should NOT dominate the entire screen.

Do not create enormous typography that covers the photograph.

The face must remain clearly visible.

━━━━━━━━━━━━━━━━━━━━━━
INTRODUCTION
━━━━━━━━━━━━━━━━━━━━━━

Use only a very short description.

Example:

"A documented collection of the man,
the myths, the memes and the
questionable decisions."

Then:

"Compiled by people who unfortunately know him."

Keep it concise.

The homepage should not contain a biography.

━━━━━━━━━━━━━━━━━━━━━━
THREE MAIN BUTTONS
━━━━━━━━━━━━━━━━━━━━━━

The homepage has exactly three main navigation choices:

PHOTOS

THE CRIMINAL

SPECIAL ROOM

These are the primary interactive elements.

The buttons should be inspired by the visual language of classic game-menu buttons, especially dark pixel-game interfaces.

IMPORTANT:

Do NOT copy Minecraft's UI directly.

Instead, create an original button style inspired by:

- dark gray textured surfaces
- subtle pixel-like borders
- thin highlights
- darker bottom edge
- centered typography
- slight depth
- subtle pressed state

The buttons should look like part of a game interface while still fitting the cinematic website.

Example:

┌──────────────────────────────┐
│            PHOTOS            │
└──────────────────────────────┘

┌──────────────────────────────┐
│        THE CRIMINAL          │
└──────────────────────────────┘

┌──────────────────────────────┐
│        SPECIAL ROOM          │
└──────────────────────────────┘

Keep them elegant and compact.

Do NOT make them giant rounded SaaS buttons.

━━━━━━━━━━━━━━━━━━━━━━
BUTTON INTERACTIONS
━━━━━━━━━━━━━━━━━━━━━━

Default:
dark gray / black

Hover:
- subtle brightness increase
- orange accent
- slight scale or position change
- cursor interaction

Pressed:
- tiny downward movement
- darker surface

The interaction should feel like pressing a game menu button.

Keep animations subtle.

━━━━━━━━━━━━━━━━━━━━━━
SPECIAL ROOM
━━━━━━━━━━━━━━━━━━━━━━

Do NOT explain what the Special Room contains.

It should create curiosity.

Add a tiny piece of metadata near it if useful:

ACCESS RESTRICTED

or:

UNKNOWN DESTINATION

The user should wonder:

"What the hell is in there?"

The actual game/birthday reveal will eventually be associated with this area.

Do NOT implement the game on this page.

━━━━━━━━━━━━━━━━━━━━━━
THE CRIMINAL

THE CRIMINAL

CASE FILE

That belongs inside the page.

PHOTOS
━━━━━━━━━━━━━━━━━━━━━━

The Photos button leads to the cinematic photo archive.

Do not show a photo grid on the homepage.

Only the button belongs here.

Keep the navigation extremely minimal.

Top-left:

/ / IDIOT

or:

MENU →

Do not create a large traditional navigation bar.

The three main destinations are already visible.

━━━━━━━━━━━━━━━━━━━━━━
CUSTOM CURSOR
━━━━━━━━━━━━━━━━━━━━━━

The website will use the subject's ugliest photograph as a custom cursor on desktop.

Design the UI so this cursor can be added later.

The cursor should not be visually necessary for understanding the interface.

Do not use custom cursor interactions on mobile.

1440 × 900.

Everything must fit inside the viewport.

NO SCROLLING.

Think of the homepage as a cinematic game menu.

Visual hierarchy:

1. Hero photograph
2. Subject name

4. Small metadata

━━━━━━━━━━━━━━━━━━━━━━
ANIMATION
━━━━━━━━━━━━━━━━━━━━━━

Initial page load:

1. black background
2. photograph softly reveals
3. subject information fades/slides in
4. navigation buttons appear
5. subtle ambient movement

Keep animations cinematic and restrained.

Do NOT use:
- bouncing
- spinning
- excessive parallax
- particles
- flashy 3D
- excessive blur

Respect reduced-motion preferences.
